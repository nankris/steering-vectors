# steering-vectors

Three independent studies of activation-steering strength and layer sweeps on Qwen3 models. Each folder has its own README, code, raw results, charts and verdict. The later two build on the first and link back to it.

- [`original-run`](original-run/): Steering vectors, "Golden-Gate my model" (Eiffel Tower edition) — **INCONCLUSIVE (leaning "no sweet spot")**
- [`steering-sweet-spot`](steering-sweet-spot/): Is there a steering-vector sweet spot? — **DISPROVEN**
- [`steering-fine-sweep`](steering-fine-sweep/): A finer steering sweep (Eiffel Tower on Qwen3-4B) — **DISPROVEN**

Known problems found in an independent review are listed in [`issues-found/`](issues-found/).
